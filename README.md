# 员工培训考试与证书到期提醒系统

任务类型：0-1代码生成

业务领域：全栈Web应用

修改范围：跨模块多文件

任务难度：中等偏难

题面：

做一个员工培训考试与证书到期提醒系统，人事创建课程、考试题库、岗位要求和证书有效期，员工学习后参加考试，通过后生成证书记录。正常路径要支持报名、学习进度、考试提交、自动判分、补考、证书发放和到期提醒。未完成课程参加考试、重复提交试卷、补考次数超限、岗位必修课缺失、过期证书继续用于岗位达标都要拦截。系统需要员工达标看板、考试明细、证书状态和导出功能，导出包含岗位、课程、成绩、证书有效期和提醒记录。重启后学习进度、成绩、证书状态和导出历史保持可查。验收还要覆盖题库版本变更、补考成绩覆盖规则和证书续期。
